=======
Editors
=======

Send pages
==========

#.  Open Web, Translations and pick a page in the page tree.
#.  Pick how many levels of subpages to send.
#.  Pick the target languages. Add a due date and a note if you need them.
#.  Click Send. The next sync run sends the package.

..  figure:: /Images/use-02-send.png
    :alt: The Send for translation form
    :class: with-shadow

..  figure:: /Images/use-03-package-sent.png
    :alt: The package in the list after the sync
    :class: with-shadow

Follow a package
================

The list shows each package with the state of each language. Open a package to
see its items, the review reasons from DigitalTolk and the preview of a
translation. Items that changed after sending are flagged. Their translation
is based on an older version.

Import a translation
====================

#.  Open the package and click Preview to compare source and translation.

    ..  figure:: /Images/use-04-preview.png
        :alt: The preview of a delivered language
        :class: with-shadow

#.  Click Import. The next sync run imports the translation and reports it to
    DigitalTolk.

    ..  figure:: /Images/use-05-imported.png
        :alt: The import summary
        :class: with-shadow

New translations are imported hidden in review mode. Check them and make them
visible.

..  figure:: /Images/use-06-page-module.png
    :alt: German and the imported English in the Page module
    :class: with-shadow

Cancel
======

You can cancel a package that waits for review at DigitalTolk. A package that
is ordered cannot be cancelled from TYPO3.
